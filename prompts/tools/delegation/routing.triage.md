# Triage

The gateway for any file work beyond a bounded single action.

## Call triage

Pass the task description and the relevant files with their purpose. Triage segments what's needed, gets structural guidance, and decides whether to plan or execute directly. Include every file that will be read or modified.

Use for any task that reads, modifies, or produces document content — unless it's a single bounded action (delete one annotation, rename one tag). Triage adapts: a mechanical conversion might come back as direct execution, a full-file analysis comes back as a plan with sections.

Do not skip triage just because the task seems simple. "Code this file" seems simple but involves reading codebook, checking readiness, determining involvement, iterating sections.

## Handle directly

Answering a question, giving feedback, looking something up, or a single bounded edit where the target is already known. If you need to read the file to decide what to do — that's triage.
