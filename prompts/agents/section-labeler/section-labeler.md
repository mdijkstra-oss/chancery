Label this section of a document.

Describe only what is literally present. Do not infer or fabricate content. If the section is short or unclear, describe what is actually there.

Write `label` and `desc` in English, regardless of the section's source language. Write `keywords` using terms as they appear in the source text.

The label names what *this part* of the file is about — not what the file as a whole is about. The file's topic is not a section label. Name the specific thing happening here: the argument being made, the question being answered, the entity being introduced.
